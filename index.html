果蝇大脑与 Transformer 讨论笔记

1. 项目定位

eonsystemspbc/fly-brain 不是”果蝇大脑玩具”，而是”拿真实果蝇大脑当尺子，给 6 种仿真软件测速度和准确度”的基准测试工具。

  • 模型：13.8 万神经元、约 500 万突触（基于 Nature 2024 论文）。
  • 做的事：① 模拟光遗传刺激实验；② 给 6 个后端测速；③ 以 Brian2(CPU) 为准，校验其他后端的准确度。

2. 与具身智能的关系

该项目本身不做具身，是”上游地基”：先解决”大脑怎么又快又准地跑起来”，具身项目（如 erojasoficial-byte/fly-brain、FlyDrones、Lulzx/fly-brain）再给它接上身体做动作。

3. Brian2 与 LIF 模型

Brian2 用三个对象搭脑：NeuronGroup（LIF 方程定义神经元）、Synapses（连接 + 权重）、PoissonInput（外部刺激）。

LIF（漏电积分-放电）方程核心：

  • dv/dt = (v_0 - v + g)/t_mbr：膜电位向静息电位回归，受输入 g 驱动；
  • dg/dt = -g/tau：输入信号随时间衰减（”漏电”）；
  • 电压到阈值 v_th 就放电，随后复位并进入不应期。

4. LIF 是否通用

方程形式通用，参数必须按物种调。 果蝇那套参数（静息 -52mV、阈值 -45mV、膜时间常数 20ms、突触时间常数 5ms、不应期 2.2ms、传导延迟 1.8ms）全部专门查自果蝇文献，不是拿老鼠/人的值套用。

5. LIF vs Transformer

维度 LIF 神经元 Transformer
输出 脉冲（二值、稀疏） 连续浮点数
时间 动态系统，随时间演化 静态一步到位，时间靠位置编码
记忆 膜电位衰减（短时） 注意力 / KV Cache（显式、长程）
编码 脉冲时间/频率 数值大小
连接 稀疏、局部 全连接、全局
权重 相对固定、局部 注意力动态、全局
学习 STDP 等局部规则 全局反向传播

共同点：都是”接收多输入 → 加权聚合 → 非线性 → 输出”的分层并行计算单元。

6. 记忆存在哪

关键澄清：LIF 的”漏电”是膜电位的物理特性，不等于”不能模拟记忆”。 记忆不存于单细胞膜电位，而存于突触权重（持久）与网络持续放电（短时）。

记忆类型 生物/LIF Transformer
长期记忆 突触权重 syn.w 训练好的网络权重
短期/工作记忆 膜电位 + 持续放电（隐式、会漏） 激活值 + KV Cache（显式、可精确查找）

7. 具身智能下 Transformer 的局限

Transformer 为”静态、离线、完整序列”设计，而具身智能需要”动态、在线、闭环”。短板：无内在时间动力学、全连接二次复杂度、无在线学习、无闭环。

神经科学是”启发源”而非”说明书”：取”稀疏、脉冲、闭环、局部学习、时间动力学”这些原则，而非照搬细节。

8. 蘑菇体（Mushroom Body）：联想学习

链路：ORN(2562) → 触角叶(50 glomeruli) → PN(686) → KC(4064，稀疏扩展约6倍) → MBON(97)。

  • 机制：每个 KC 只随机采样约 5 个 PN，把相似气味”投影到高维稀疏空间”区分开（稀疏编码）。
  • APL（仅 2 个）：旁路反馈抑制环，作用在 KC 层，调节 KC 活跃度（增益控制）。
  • 多巴胺神经元（约 340 个）：教学信号，作用在 KC→MBON 突触上，改写权重（写记忆）。

9. 中央复合体（Central Complex）：导航

  • 环形连接：8 个朝向位置首尾相接排成环。
  • 余弦权重：”近邻互助、远邻互斥”，逼出唯一一个活动亮斑（环形吸引子），亮斑位置 = 当前朝向。
  • 方向更新：PEN 通路左右偏移，让亮斑随转身沿环移动。

10. 朝向 → 转向的闭环

  • PFL3（左转）/ PFL2（右转）：把”当前朝向 vs 目标方向”的差翻译成转向指令。
  • 诚实提醒：连接组能传播到”转向相关下行神经元”，但”协调转身/走路”的节奏部分依赖外挂步态生成器，不完全是连接组自己涌现的。

11. 核心方法论：结构 ≠ 功能

连接图（谁连谁）只告诉你”在哪找功能”，不能告诉你”零件怎么运转”。

例证：用”点神经元（开关）”模拟 APL（实际是连续分级信号的”调光旋钮”），无法复现增益控制——因为零件类型搞错了，接线图再对也跑不出功能。

12. 感觉系统全景（多模态）

果蝇不是只有视觉+嗅觉，而是多模态。关键区分是”进大脑做认知”还是”进脊髓做反射”：

感觉 器官 去向
嗅觉 触角→触角叶 中央脑
视觉 复眼→视叶 中央脑
味觉 口器唇瓣、腿爪 部分进中央脑（学习），部分 VNC 反射
触觉 跗节、触角尖、全身刚毛 多走 VNC 反射
本体感觉 腿关节（角度/负载） VNC
平衡（陀螺仪） 平衡棒 haltere VNC + 飞行
振动/风速/听觉 Johnston 器官 VNC
温度 触角芒 中央脑 / VNC
  • 视觉、嗅觉是通向”大脑认知”的两条大路；触觉/本体/平衡多在腹神经索（VNC，相当于脊髓）层面就完成反射，不都上报大脑。
  • 反直觉点：果蝇用嘴和腿尝味（爪踩糖水触发伸喙 MN9）；听觉=Johnston 器官感受振动（无耳膜）；平衡棒=退化后翅，测身体旋转角速度（陀螺仪）。

13. 视觉通路：视叶三层如何逐层抽象

细胞命名：字母=层/形态，数字=亚型。R1–R8=光感受器（R1–R6 管明暗→Lamina，R7/R8 管颜色→直插 Medulla）；L1–L5=Lamina 单极细胞（L1/L2/L3 主通道，L4/L5 调节）；Mi/Tm=Medulla；T4/T5=Lobula Plate 方向选择；HS/VS=宽场光流；LC=视觉投射出口。

光感受器极性（易错点）：果蝇光感受器是光去极化——亮处活跃（与人眼相反，昆虫特性）。释放组织胺（抑制性），故 L1–L3 是 OFF 细胞（对变暗兴奋）。

ON/OFF 两条通道 = 分叉，不是串行反转：光感受器信号在 Lamina 分叉给 L1、L2 两条并列的线；Medulla 里 L1 保持 OFF（→T5 测暗边）、L2 再反转回 ON（→T4 测亮边）。层与层串行，一层内并行分叉。

三层各怎么算 + 为什么分层：

层 做什么 机制 为什么单独一层
Lamina 亮度→变化 光感受器适应（时间高通）+ 侧抑制（空间高通） 绝对亮度无用，只留变化
Medulla 变化→朝向/颜色 组合相邻列做朝向选择；R7/R8 颜色拮抗 需跨列空间重组
Lobula/Plate 特征→运动/物体 T4/T5 方向选择（空间偏移+时间延迟）；HS/VS 求和=光流；LC 整合物体 运动是时空计算，需最深连接

T4/T5：方向选择细胞，每位置 4 方向（前后上下），T4 测亮边、T5 测暗边，靠”这里现在 + 旁边刚才”两信号比对。HS/VS 把全视野 T4/T5 求和成光流（喂飞行稳定），LC 整合成威胁/物体（送决策）。

宽场 vs 柱状（HS/VS vs LC）：感受野大小相反——HS/VS 宽场（全视野求和，空间被平均掉）→ 全局光流 → 稳定自己；LC 柱状（各守一小块，位置保留）→ 局部威胁/对象 → 追/逃。根因：全局运动=自己动（要纠正），局部物体=世界里有东西（要应对）。Medulla 给 Lobula 的是保留空间的局部特征图（每列带朝向/ON-OFF/颜色），宽场/柱状是 Lobula 两类下游对它做全局求和 vs 局部读取的结果。

“延迟”≠记忆：方向选择里的”旁边刚才”是物理延迟（膜电容充放电、多跳突触、传导距离，毫秒级），不是存储。靠快慢两路信号”同时到达”来判方向，无需记忆单元。

为什么非得三层：① 依赖链（边←变化←亮度，不能跳）；② 感受野逐层扩大（单列→几列→全视野），每种抽象需不同空间尺度；③ 每层产出不同标签通道给不同下游（威胁走最短硬连线，逃跑快至 10ms 级）。

项目实现：用 flyvis（训练出的神经网络）映射连接组，非手写电路。

14. Lulzx-fly-brain = 具身智能的最小完整样本

与第 2 节呼应：fly-brain 是”上游地基”，具身项目”接上身体”；Lulzx-fly-brain 就是接上身体后的具体样本——16.5 万神经元真实连接组 + flybody 身体 + MuJoCo 物理环境，让行为在闭环里自己冒出来。

具身智能的核心 = 闭环（vs 开环）：

  • 开环：实验者喂输入 → 看输出，网络被动、与世界无互动；
  • 闭环：大脑发命令 → 身体动 → 改变环境 → 环境反过来给感官输入 → 影响下一步命令；
  • 本项目每毫秒：读物理状态 → 翻译成感觉神经元 → 眼睛投光线给 flyvis → 大脑跑 0.5ms 脉冲步 → 运动神经元设执行器 → MuJoCo 推进。读的是物理状态，不是实验者设计的刺激——这是闭环的分水岭。

身体是计算的一部分（三个只有闭环才暴露的证据）：

现象 说明
再传入（reafference） 身体一动、脚触地，接触信号反过来把行走神经元顶到 10–13Hz，停不下来（需门控抑制）
逃逸变难 自己动 / 墙逼近 / 腿在视网膜上产生”膨胀”，与真 looming 难分（10 次 loom 仅 2 次成功）
偏差放大 左右不对称的微小偏差被累积成原地转圈（开环看不到，因开环没有位置累积）

两条诚实边界（具身智能的经典难题）：

  • 命令 ≠ 运动程序：连接组能给”往前走”的命令，但走路节律 / 姿态协调靠外部步态生成器（拟合 100 条真实轨迹）——运动智能很大一部分在身体 / 神经索，不在大脑；
  • 自发活动从哪来：何时走 / 停 / 理毛来自外部模块，不是连接组产生的。”命令的出处，和它经过哪条路径，一样重要。”

两条路线（呼应”先天 vs 后天”）：

路线 做法 代表
自下而上（发育 / 接线） 真实连接组 + 身体，看先天布线能否自发产生行为，不训练 Lulzx-fly-brain
自上而下（训练逼近） RL 在果蝇身体上训练连接组结构的控制器 Fly-connectomic Graph Model (Jin et al. 2026)

警告：训练出的控制器不一定用生物动力学，其成功不能证明”接线本身规定了运动程序”。

一句话：用”真实连接组 + 真实身体 + 物理环境”回答具身智能的核心问题——行为怎么在闭环里冒出来，哪些算大脑的功劳、哪些是身体和环境给的；最有价值的甚至是闭环逼出来的那些诚实失败。
